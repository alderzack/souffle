# Souffle

Respiration guidée : cohérence cardiaque et exercices de sophrologie. Sans compte, sans publicité, tout reste sur ton téléphone, et ça marche hors ligne.

**Ouvrir l'app : https://alderzack.github.io/souffle/**

Pour l'installer sur ton téléphone : ouvre le lien, puis
- iPhone (Safari) : bouton Partager › « Sur l'écran d'accueil » ;
- Android (Chrome) : menu ⋮ › « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Cette app ne remplace pas un avis médical.
